# 어댑터 crate

Postgres 와 네트워크에 닿는 crate 의 파일을 열 때 읽힙니다.

- **판정은 core 가 합니다.** 어댑터는 실제 DB 를 읽어 core 의 타입(`Snapshot`)으로 옮기고, core 의 계획(`Step`)을 실행합니다. 「맞는가」를 어댑터에서 다시 따지지 않습니다.
- **실제 DB 로 잽니다.** 역할 · 권한 · 격리의 테스트는 `ORBITAL_PG` 의 PostgreSQL 에 인스턴스를 세워 그 역할로 실제로 접속해 봅니다.
  테스트마다 식별자를 새로 지어 서로 섞이지 않게 하고, 끝나면 세운 것을 걷습니다.
- ❌ 비밀번호를 만들거나 저장하지 않습니다. 역할에는 비밀번호가 없고, DB 는 proxy 만 닿는 자리에서만 연결을 받습니다.
- ❌ 운영 데이터의 행을 결과나 오류에 싣지 않습니다. 예행연습의 결과는 숫자뿐입니다.
- 오류는 무엇을 하다 깨졌는지와 함께 올립니다. Postgres 의 오류 문구를 그대로 내보낼 때는 행의 값이 섞이지 않는지 봅니다.
