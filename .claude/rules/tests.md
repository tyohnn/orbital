# 테스트

통합 테스트를 열 때 읽힙니다. 단계를 고르는 기준은 루트 `CLAUDE.md` 의 「테스트의 사다리」입니다.

- **테스트 이름은 참이어야 하는 것을 한국어 문장으로 적습니다.** 함수 이름을 되풀이하지 않고, 경계는 양쪽(들어가는 끝 · 들어가지 않는 끝)을 각각 적습니다.
- **속성 테스트는 구현을 다시 부르지 않는 오라클과 비교합니다.** 같은 함수로 기대값을 만들면 늘 초록입니다. 생성기의 입력에서 기대값을 바로 찾습니다.
- **생성기는 경계가 자주 나오게 좁힙니다.** 인스턴스 식별자를 `k3f9x2ab` 와 `k3f9x2abc` 둘로 두면 머리말이 겹치는 경우가 수시로 나옵니다.
- **막는 테스트는 실제로 시도해 봅니다.** 「못 한다」는 권한이 없다는 조회가 아니라, 그 역할로 접속해 해 봤을 때 거절되는 것으로 잽니다.
- `proptest` 가 실패하면 남기는 `*.proptest-regressions` 파일은 커밋합니다.
- ❌ 테스트를 끄거나 `#[ignore]` 로 초록을 만들지 않습니다.
